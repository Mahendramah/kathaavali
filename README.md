# ಕಥಾವಳಿ — Kannada Stories & Poems Website

A fully static, mobile-friendly Kannada stories and poems website. It has no server or database requirement, so you can host it free on GitHub Pages, Netlify, or Cloudflare Pages.

## Run it on your computer

Open `index.html` in a modern browser. No installation is required.

## Personalize it

- Replace `hello@example.com` in `samparka.html` and `app.js` with your public email address.
- Edit stories in `kathegalu.html` and their full text in `app.js`.
- Edit poems in `kavanagalu.html` and their full text in `app.js`.
- The multi-page site uses: `index.html`, `kathegalu.html`, `kavanagalu.html`, `barahagara.html`, `suddipatra.html`, and `samparka.html`.

## Important note about the newsletter

The newsletter form currently shows a success message but does not save emails. To collect email addresses, connect it to a service such as Formspree, Mailchimp, or Buttondown later.

## Publish for free

1. Create a GitHub account and a new repository, for example `kannada-kathegalu`.
2. Upload every `.html`, `.css`, and `.js` file to the repository root.
3. In the repository, open **Settings → Pages** and deploy from the `main` branch.
4. GitHub will give you a shareable public website address.
